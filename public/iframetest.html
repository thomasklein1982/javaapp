Java-App per iframe einbinden

Anleitung
  • Java-App kann per iframe eingebunden werden. Der HTML-Code dazu lautet
    <iframe src="https://thomaskl.uber.space/Apps/java-app/#id=0;"></iframe>
  • Die ID kann auch weggelassen werden. Sie dient dazu, leicht zu identifizieren, von welcher JavaApp eine Nachricht kommt, für den Fall, dass mehrere iframes mit JavaApp eingebunden werden.
  • Per JavaScript der Form iframe.contentWindow.postMessage({type: 'command', data: {...}},"*"); können Befehle an JavaApp gesendet werden, z. B.
    iframe.contentWindow.postMessage({type: 'open-project-empty'},"*");
    um ein neues leeres Projekt zu öffnen.
  • JavaApp sendet aktiv Ereignisse an das Eltern-Fenster.
    1. Um diese Ereignisse und andere Antworten von JavaApp zu empfangen, muss man die onmessage-Methode von window implementieren, z. B. so 
      window.onmessage=function(message){
  message=message.data;
  console.log(message.id,message.type,message.data);
  if(message.event){
    //Ereignis von JavaApp
    ...
  }else if(message.type==="give-current-class-answer"){
    //Antwort der Anfrage "give-current-class"
    ...
  }else ...
}
    2. JavaApp sendet ready, wenn die App vollständig geladen ist und verwendet werden kann.
  • Gesendete Befehle bewirken, dass JavaApp eine Antwort schickt:
    1. Bei Anfragen wie "give-current-class" (die alle mit "give" anfangen) ist der type immer der type der Anfrage, gefolgt von "-answer". Im obigen Fall also "give-current-class-answer".
    2. Bei anderen Befehlen sendet JavaApp eine Antwort der Form "[Type des Befehls]-done", also z. B. "open-project-empty-done"
